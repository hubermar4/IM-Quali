# Historical qualification races and slots, 2017-2026

Where athletes could qualify for the IRONMAN / IRONMAN 70.3 World Championship, and how many age-group slots each race offered. Generated by [build_race_slot_history.py](../src/build_race_slot_history.py) from the cached Coach Cox qualification-cycle pages ([source data](../data/derived/coachcox_qualifiers_2017_2026.md)). Rules that apply to each cycle: [historical_qualification_rules.md](./historical_qualification_rules.md).

- A race is listed under the qualification cycle in which it was held (late-season races belong to the following cycle).
- Slot numbers are the totals published by Coach Cox; where men and women have separate quotas they are shown as `(M/W)`. Several editions in one cycle are joined with `+`.
- Races are grouped by Coach Cox series, so renamed races (e.g. Kalmar / Sweden, Kopenhagen / Copenhagen) are one row. `—` means the race was not a qualifier in that cycle.
- Slot totals include slots that were not accepted or rolled down.
- The 2027 cycle is not included in the cached data (in progress); see [im_qualification_race_slots.md](./im_qualification_race_slots.md).
